# Skill: Game QA Tester

## Objetivo
Criar e executar suítes de testes automatizados com Vitest / Node Test Runner e simulações para certificar a estabilidade de regras de gameplay e economia do NoobRPG.

## Escopo de Testes
- **Testes Unitários:** Fórmulas de XP, dano de combate, taxas de dedução do mercado (5%).
- **Testes de Integração:** Fluxos de autenticação, transações de compra e venda no mercado, persistência de inventário.
- **Simulações de Carga:** Simulação de 1.000 jogadores virtuais para análise de inflação monetária e gargalos de processamento.
- **Validação de Critérios de Aceite:** Verificar a conformidade estrita antes de avançar qualquer fase do Roadmap.
